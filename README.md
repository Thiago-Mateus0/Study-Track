#  Study Track

Prazer, sou o Thiago, calouro na faculdade e esse é meu primeiro projeto pessoal.

Uso o app YPT todo dia e quando entrei na faculdade pensei: por que não criar algo parecido pra acompanhar meus próprios estudos? Foi daí que surgiu o Study Track.

---

## O projeto

Simples, lógico e funcional. Feito com comandos básicos que estou aprendendo agora:

- `if / elif / else`
- loop `while`
- `input()`
- listas e dicionários
- leitura e escrita em `.json`

Nada além do que eu sei explicar.

---

## Como rodar

```bash
python main.py
```

---

## O que faz

- Registrar tópicos estudados e o tempo dedicado
- Ver todas as sessões e o total de minutos
- Definir uma meta diária de estudo
